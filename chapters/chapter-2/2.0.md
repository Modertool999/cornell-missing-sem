# Why Git?

In Chapter 1, we looked at how your computer organizes files and directories. Most of the time, however, we do not work with each file in complete isolation. Instead, we group related files and directories together to form a project.

For example, a small programming project might be contained 

main.py contains the program itself;
tests.py contains tests for the program; and
README.md explains what the project does and how to use it.

A project may contain only a few files, or it may contain thousands of files organized across many directories. In either case, we can think of the project as a particular directory together with all of the files and subdirectories contained inside it.
